# 💻 English Syntax as Code (v2.0)

> [!NOTE]
> 英語の文型（SV, SVC, SVO...）を「プログラミング言語のオブジェクト指向構文」に見立てて解説する、理系・エンジニアに特におすすめの学習モジュールです。

## 🎯 アプリの目的と概要
「主語がメソッドを実行する」「主語のプロパティに値を代入する」というエンジニアになじみ深いメタファーを用いて、英語の5文型を直感的に理解します。

## ✨ 主な機能と特徴

### 1. 5文型のプログラミング的解釈
- **SV (自己完結メソッド)**: `Subject.Verb()`  (例: `I.run()`)
- **SVC (プロパティの代入)**: `Subject.State = Complement` (例: `She.state = "Happy"`)
- **SVO (引数を取るメソッド)**: `Subject.Verb(Object)` (例: `I.eat("apple")`)
- **SVOO (2つの引数)**: `Subject.Verb(Person, Object)`
- **SVOC (メソッドによる状態変化)**: `Subject.Verb(Object, TargetState)`

### 2. コードと英文の比較表示
画面上で実際の「英文」と「対応する擬似コード」が左右（または上下）に並んで表示され、論理的な構造の把握を助けます。

## 🚀 使い方 (Usage Guide)
1. 目次（Contents）から学習したい文型パターン（パターン1〜5）を選択します。
2. 提示される擬似コードと実際の英文を見比べ、動詞が「どのような引数（目的語）を要求しているか」を理解します。
