# 🧩 Grammar Puzzles - Syntax Engine

## 🎯 アプリの目的と概要
単語や句（フレーズ）を正しい文法規則（S, V, O, C, M）に従って並べ替える、インタラクティブな構文パズルゲームです。

## ✨ 主な機能と特徴
- **ドラッグ＆ドロップ UI**: 画面上に散らばった単語ブロックを、マウスやタッチ操作でドラッグし、正しいスロット（S, V, O など）にはめ込みます。
- **即時判定ロジック**: ブロックをはめ込むと、内部のシンタックス・エンジンがリアルタイムに文法的整合性をチェックし、正解・不正解をフィードバックします。
- **ヒント機能**: つまずいた時のために、次に入るべき品詞や要素をサジェストするヒントボタンを搭載。
- **音声読み上げ機能**: 完成した文章を「🔊 Listen」ボタンで再生し、発音を確認できます。また、自動解答とともに音声だけを聞き流す「Listen Only」モード（Auto-Solve）も搭載されています。

## 🚀 使い方 (Usage Guide)
1. **パズルの開始**: アプリを開くと、シャッフルされた単語ブロックが表示されます。
2. **ブロックの配置**: 「Subject (主語)」「Verb (動詞)」などの空枠に、該当するブロックをドラッグします。
3. **完成と採点**: すべてのブロックを配置し終えると自動で採点され、次のステージへ進みます。
4. **リスニング**: 正解時または「Listen Only」モード選択時に、文章の音声再生が行われます。再生中は「🔊 Playing Audio」と表示されます。
   > [!TIP]
   > 動詞（Verb）を最初に見つけて配置すると、その前後のSとO/Cが推測しやすくなります！
