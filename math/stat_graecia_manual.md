# 🏛 Stat Graecia (統計学ギリシャ文字クイズ)

## 🎯 アプリの目的と概要
**Stat Graecia** は、統計学で頻繁に使用されるギリシャ文字（$\mu, \sigma, lpha, eta$ など）とその統計的意味（母平均、標準偏差など）の結びつきを完璧に暗記するための特化型トレーニングツールです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **統計学特化データセット** | 一般的なギリシャ文字の読み方だけでなく、「統計学において何を意味するか」に焦点を当てた出題を行います。 |
| **双方向テストモード** | 「記号を見て意味を答える」モードと、「意味を見て記号を答える」モードの両方に対応しています。 |
| **シャッフルアルゴリズム** | 出題順序と選択肢の配置が毎回ランダムに生成され、場所で覚えてしまうのを防ぎます。 |

> [!TIP]
> 統計学の学習初期において、「文字の定義」でつまずくことは非常に多いです。このアプリで $\sigma$ と $\sigma^2$ の違いなどを反射レベルに落とし込むことで、数式の理解スピードが飛躍的に上がります。

## 🚀 使い方 (Usage Guide)
1. アプリを起動し、問題（ギリシャ文字または統計用語）を確認します。
2. 正しいペアとなる選択肢をクリックします。
3. クイズ終了後にスコアが表示されるので、満点を取れるまで再挑戦してください。
