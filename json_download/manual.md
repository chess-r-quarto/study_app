# ⚡ JSON Downloader (Vite/React版)

## 🎯 アプリの目的と概要
**JSON Downloader (Vite)** は、ReactとViteのモダンなフロントエンド環境で構築された、高度なJSON編集およびダウンロードツールです。素のHTML版と比較して、よりインタラクティブで堅牢なUIを提供します。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **シンタックスハイライト** | ReactコンポーネントによるリアルタイムのJSONシンタックスハイライトを提供し、可読性を向上させます。 |
| **React/State管理** | 巨大なJSONファイルであっても、仮想DOMとReactのState管理によりUIがフリーズすることなくスムーズに操作できます。 |
| **モジュラー設計** | 今後の機能拡張（スキーマ検証や外部API連携など）を見据えた、拡張性の高いViteベースのプロジェクト構造を採用しています。 |

## 🚀 使い方 (Usage Guide)
1. エディタ領域にJSONテキストを入力します。シンタックスハイライトが自動的に適用されます。
2. データ構造を確認し、必要に応じてUI上で直接編集（キーの追加や値の変更）を行います。
3. **[Download JSON]** ボタンをクリックし、最新のステートをファイルとして保存します。
