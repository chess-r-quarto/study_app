コース1 / タスク1: サステナビリティ・コンセプトカード

人類が直面する壮大な課題（Grand Challenges）とSDGs目標を起点に、解決すべき課題領域を定義します。

TASK_01_CONCEPT

持続可能なイノベーション 4Pモデル

検証の優先順位原則: People（社会的望ましさ） -> Planet（環境の必要性） -> Profit（経済的実行可能性） -> Progress（技術的実現可能性）

MODEL_4P
PHASE 1: PEOPLE

社会的望ましさ (Social Desirability)

顧客・地域・従業員が本当に望んでいるか？

->
PHASE 2: PLANET

環境の必要性 (Environmental Necessity)

生態系や地球資源の循環に資するか？

->
PHASE 3: PROFIT

経済的実行可能性 (Economic Viability)

持続的に利益を生み、回収できるか？

->
PHASE 4: PROGRESS

技術的実現可能性 (Technological Feasibility)

新技術やインフラを実装可能か？

イノベーション野心マトリックス (Innovation Ambition Matrix)

縦軸: ビジネスモデル適合度（既存 vs 新規） / 横軸: 技術コンピテンシー（既存 vs 新規）から野心の立ち位置を選択します。

MATRIX_2x2
破壊的 (Disruptive) [SELECTED]

新ビジネスモデル x 既存技術

実証済みの技術を用いて、市場の商慣習や課金形態を根本的に変革する。

建築的 (Architectural) [SELECTED]

新ビジネスモデル x 新技術

先端研究開発と完全な新システムを融合し、新たな産業構造を創造する。

漸進的 (Incremental) [SELECTED]

既存ビジネスモデル x 既存技術

現行製品・プロセスの効率化や資源消費削減の改善を積み重ねる。

急進的 (Radical) [SELECTED]

既存ビジネスモデル x 新技術

現行の取引関係を維持しつつ、革新的な材料・省エネ技術等を導入する。

コース2 / タスク2: システム思考・因果関係マップとレバレッジポイント

ステークホルダー（関係者）とノード（測定可能な要因）を区別し、正負の因果関係[+] / [-]と介入点（レバレッジポイント）を特定します。

SYSTEM_DYNAMICS
[STAKEHOLDER] ステークホルダー

意思決定に関わる個人または組織（例: 自治体、消費市場、物流業者）。

[NODE_VARIABLE] システムノード（変数）

時間経過で増減・測定可能な要因（例: 廃棄処分費用、容器回収率、環境意識水準）。

因果関係ループ & レバレッジポイント一覧

原因ノード (Cause Node) 極性 結果ノード (Effect Node) レバレッジ点? 因果関係の背景・介入メカニズム 削除

「How Might We? (HMW: どうすれば〜できるか？)」ステートメント作成

特定したレバレッジポイントを元に、定型フォーマットに落とし込みます: どうすれば [達成したい行動] + [影響を与えたい対象] によって [理想的な成果] を実現できるだろうか？

どうすれば、[回収インセンティブと集荷ネットワークを最適化し] + [都市部一般消費者の返却行動] によって、[容器回収率95%以上とサプライチェーン全体のプラゴミ半減] を実現できるだろうか？
