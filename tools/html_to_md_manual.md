# 📄 HTML to MD & PDF Converter

## 🎯 アプリの目的と概要
**HTML to MD & PDF Converter** は、ユーザーが入力したHTMLコードをリアルタイムでクリーンな Markdown に変換し、さらにそのままPDFとして出力・保存できる強力なドキュメント作成支援ツールです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **リアルタイム変換** | 左ペインにHTMLを貼り付けると、Turndown.js を用いて右ペインにMarkdownが即座に生成されます。 |
| **PDFエクスポート** | 変換されたコンテンツをブラウザの印刷機能を介して美しいPDFとして保存できます。 |
| **Lichess UI** | 長時間の作業でも目が疲れない、ダークモード（Lichessスタイル）を採用。 |

> [!TIP]
> **Turndown.js のロジック**: 内部ではHTMLのDOMツリーを再帰的に走査し、`<h1>` を `#` に、`<ul>` を `-` にマッピングしています。不要なタグは自動的にフィルタリングされます。

## 🚀 使い方 (Usage Guide)
1. 画面左側のエディタ領域に、変換したい対象のHTMLコードを貼り付けます。
2. 画面右側にMarkdownが自動生成されるのを確認します。
3. プレビューボタンを押してレンダリング結果を確認し、**[PDFとして保存]** ボタンで書き出します。
