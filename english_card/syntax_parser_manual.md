# 🔍 Syntax Parser (構文解析器)

## 🎯 アプリの目的と概要
入力された英文を単語レベルで分解し、それぞれの品詞や文の要素（S, V, O, C, M）をタグ付けしてツリー状に解析結果を表示するインタラクティブなパーサーです。

## ✨ 主な機能と特徴
- **構文解析エンジン**: 内部の自然言語処理ロジックを用いて、単語ごとの品詞（Noun, Verb, Adjective等）を自動判定（※またはあらかじめタグ付けされたデータベースに基づく表示）。
- **ドラッグ＆ドロップ UI**: （バージョンにより）ユーザー自身が単語に S, V, O, C のタグをドラッグしてアサインし、答え合わせができる機能が含まれます。
- **ハイライト表示**: 特定の品詞だけをハイライト（例: 「すべての動詞を赤にする」）して、文脈を際立たせます。

## 🚀 使い方 (Usage Guide)
1. **テキスト入力/選択**: 解析したい英文を選びます。
2. **解析結果の確認**: 画面下部に表示されるシンタックストリーを確認し、どの句(Phrase)がどこに掛かっているかを確認します。
3. **自己テスト**: タグ付けが手動のモードの場合、自分で S, V, O, C を単語に割り当ててから正解を確認します。
