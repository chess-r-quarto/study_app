# 📊 FP1 Portfolio Management (ポートフォリオ分析ツール)

## 🎯 アプリの目的と概要
**FP1 Portfolio Management** は、2資産間のポートフォリオの期待収益率、リスク（標準偏差）、相関係数、およびシャープレシオを計算・視覚化するツールです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **リスク・リターン計算エンジン** | 組み入れ比率（ウェイト）をスライダーで動かすと、ポートフォリオ全体の期待リターンとリスクがリアルタイムで再計算されます。 |
| **相関係数シミュレーション** | 相関係数（-1.0 〜 +1.0）を変更することで、分散投資によるリスク低減効果（ポートフォリオ効果）がどのように変化するかを学べます。 |
| **シャープレシオ計算** | 無リスク利子率（リスクフリーレート）を入力することで、投資効率を示すシャープレシオを自動算出します。 |

## 🚀 使い方 (Usage Guide)
1. 資産Aと資産Bの「期待収益率（%）」と「標準偏差（リスク）」を入力します。
2. 2資産間の「相関係数」を設定します。
3. 画面上のスライダーを使って、資産Aの投資比率（0%〜100%）を動かします。
4. グラフ上のプロットが動き、最もリスク対リターンが良いポイント（効率的フロンティア上）を視覚的に探すことができます。
