# 📚 FP1 Static Data (法令・税率リファレンス)

## 🎯 アプリの目的と概要
**FP1 Static Data** は、FP1級の計算問題において必要となる「常に変動する法定数値（税率、控除額、社会保険料率など）」を一覧化し、辞書のように素早く引くことができる静的データ・リファレンスです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **最新法令ベースの係数表** | 「終価係数」「現価係数」「年金現価係数」などの6つの係数表を収録しています。 |
| **速算表の一元管理** | 所得税の速算表、相続税の速算表、贈与税の速算表（一般・特例）をタブで切り替えて閲覧できます。 |
| **社会保険料率** | 協会けんぽの保険料率や、国民年金保険料の当年度の月額などの固定値を記載しています。 |

> [!IMPORTANT]
> **法令基準日について**
> FP1級試験は、試験日ごとの「法令基準日」が存在します。本ツールは原則として最新の法令に追従していますが、実際の試験では問題冊子の巻末に与えられるデータを優先してください。

## 🚀 使い方 (Usage Guide)
1. 学習中や他のシミュレータを使用中に、「あれ、所得税の税率って今の金額帯だと何%だっけ？」と疑問に思った際に開きます。
2. サイドバーから該当する税目（所得税、相続税など）を選択し、表から数値を拾い出します。
