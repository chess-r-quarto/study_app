# 👴 FP1 Pension Simulator (公的年金シミュレータ)

## 🎯 アプリの目的と概要
**FP1 Pension Simulator** は、日本の複雑な公的年金制度（老齢基礎年金および老齢厚生年金）の受給見込額を、加入月数と平均標準報酬額から概算するための計算ツールです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **二階建て構造の計算** | 1階部分（国民年金）と2階部分（厚生年金）を独立して計算し、合算結果をダッシュボードに表示します。 |
| **免除期間の反映** | 国民年金の計算において、全額免除や半額免除の月数を加味した国庫負担割合の計算ロジック（平成21年3月以前/以後の分岐）を実装しています。 |
| **経過的加算の算出** | 厚生年金の定額部分と基礎年金の差額（経過的加算）をシミュレートします。 |

> [!TIP]
> 報酬比例部分の計算において、「平成15年3月以前」の平均標準報酬月額と、「平成15年4月以後」の平均標準報酬額（総報酬制）の乗数の違い（7.125/1000 と 5.481/1000）を正確に分けて入力・計算することができます。

## 🚀 使い方 (Usage Guide)
1. 「基礎年金」タブで、加入月数（納付済、免除等）を入力し、1階部分の金額を確認します。
2. 「厚生年金」タブで、平均給与（標準報酬額）と加入月数を入力します。
3. 画面右側に、65歳以降に受け取れる年金の総額（年額・月額）が表示されます。
