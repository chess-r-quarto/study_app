# 🏡 FP1 小規模宅地等の特例 (Small Scale Land Tax Relief)

## 🎯 アプリの目的と概要
本アプリは、相続税対策において最も重要とされる**「小規模宅地等の特例」**の限度面積と減額割合を正確に計算し、土地の評価額をどれだけ引き下げられるかをシミュレートするツールです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **用途ごとの適用限度面積** | 「特定居住用宅地等（330㎡まで80%減額）」や「特定事業用宅地等（400㎡まで80%減額）」のロジックを網羅しています。 |
| **完全併用の計算** | 居住用と事業用を併用する場合の完全併用（最大730㎡）の特例ルールに対応しています。 |
| **貸付事業用の調整計算** | 貸付事業用宅地等（200㎡まで50%減額）が含まれる場合の複雑な面積調整計算（算式）を自動で行います。 |

> [!NOTE]
> **FP1試験の最頻出項目**
> 複数の用途の土地がある場合、どの土地から優先して特例を適用すれば「減額される金額が最大になるか」を選択するロジックが組み込まれています。

## 🚀 使い方 (Usage Guide)
1. 相続した土地の「自用地としての評価額」と「地積（㎡）」を入力します。
2. その土地が「居住用」「事業用」「貸付用」のどれに該当するかを選択します。
3. **[計算実行]** を押すと、特例適用後の評価額（相続税の課税価格に算入される金額）が表示されます。
