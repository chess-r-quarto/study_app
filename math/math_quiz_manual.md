# ♟️ Mathchess (Mathematical Symbol Quiz)

## 🎯 アプリの目的と概要
**Mathchess** は、高度な数学論文やテキストを読む際に障壁となる「数学記号（$\sum, \int, \in$ など）」の読み方や意味を、ゲーム感覚で素早く認識できるように鍛えるクイズアプリです。

## ✨ 主な機能と特徴
| 機能 (Feature) | 説明 (Description) |
| :--- | :--- |
| **LaTeXレンダリング** | MathJax/KaTeX等を利用し、ブラウザ上で美しい数学数式・記号を描画します。 |
| **多肢選択式クイズ** | ランダムに提示される数式記号に対し、正しい名称や意味を選択肢から選びます。 |
| **LichessスタイルUI** | チェスアプリ「Lichess」を彷彿とさせる、集中力を高めるダークモードの洗練されたデザイン。 |

> [!NOTE]
> **学習ロジック**: 数学記号を「目で見て意味を思い出す」までのレイテンシ（遅延）を削ることが目的です。反射的に答えられるようになるまで反復してください。

## 🚀 使い方 (Usage Guide)
1. "Mathematics" カテゴリから "Mathchess" を起動します。
2. 画面中央に大きく数学記号が表示されます。
3. 提示された記号の正しい読み方・意味を、4つの選択肢の中から素早くクリックします。
